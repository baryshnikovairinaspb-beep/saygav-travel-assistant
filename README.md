# SAYGAV Travel Assistant

Одностраничный интерактивный помощник для путешествий со служебными собаками. Пользователь выбирает страну, город и транспорт, получает предварительный чек-лист документов, отмечает выполненные шаги, находит парки и сохраняет план в PDF.

## Просмотр

Откройте `index.html` в браузере. Сайт не требует сборки и внешних библиотек.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите файлы проекта в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch, Branch: `main`, Folder: `/ (root)`.
5. Сохраните настройки и дождитесь появления опубликованной ссылки.
